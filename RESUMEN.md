### **Post #1: Introducción a los Grafos** 
`posts/post1.html` - 8 minutos de lectura

**Temas:**
- Definición de grafos (G = V, E)
- Vértices, aristas y conceptos clave
- Tipos de grafos (dirigidos, no dirigidos, ponderados)
- Grafo conexo y cíclico
- Ejemplo visual interactivo con Canvas (5 nodos)
- Código Python de ejemplo
- Aplicaciones prácticas en el mundo real

**Visualización:**
```

   / \
  B   C
 / \ / \
D   E   (conexiones)
```

### **Post #2: Representación de Grafos**
`posts/post2.html` - 10 minutos de lectura

**Temas:**
- **Lista de Adyacencia** 
  - Estructura: O(V+E) espacio
  - Ideal para grafos dispersos
  - Código Python con diccionarios
  
- **Matriz de Adyacencia**
  - Estructura: O(V²) espacio
  - Ideal para grafos densos
  - Tablas de ejemplo para grafos dirigidos/no dirigidos
  
- Comparación de complejidad
  - Insertar/eliminar vértices
  - Verificar aristas
  - Encontrar vecinos
  
- Cuándo usar cada una
- Implementación en Python

**Tablas Incluidas:**
- Matriz de ejemplo (5x5)
- Comparación de operaciones

### **Post #3: Algoritmos de Recorrido**
`posts/post3.html` - 12 minutos de lectura

**Temas:**
- **BFS (Breadth-First Search)**
  - Búsqueda por amplitud
  - Usa cola (queue)
  - Encuentra camino más corto
  - Pseudocódigo y Python
  
- **DFS (Depth-First Search)**
  - Búsqueda por profundidad
  - Usa pila (stack) o recursión
  - Versión recursiva e iterativa
  - Pseudocódigo y Python
  
- Comparación BFS vs DFS
  - Tabla de complejidad
  - Ventajas y desventajas
  
- Aplicaciones prácticas
  - BFS: GPS, web crawlers, redes
  - DFS: Detección ciclos, ordenamiento topológico
  
- Ejemplos completos
  - Detectar ciclos
  - Ordenamiento topológico
