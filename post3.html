Algoritmos Fundamentales de Recorrido: BFS y DFS

Introducción

El recorrido de un grafo es uno de los problemas fundamentales en ciencias de la computación. Existen dos algoritmos clásicos para recorrer todos los vértices de un grafo:

  • BFS (Breadth-First Search): Búsqueda por amplitud
  • DFS (Depth-First Search): Búsqueda por profundidad

Ambos algoritmos tienen complejidad de tiempo O(V + E), pero difieren en el orden en que visitan los vértices y en las estructuras de datos que utilizan.

Búsqueda en Amplitud (BFS)

¿Qué es BFS?

BFS es un algoritmo que explora el grafo por niveles. Comienza en un vértice raíz y visita todos los vértices a distancia k antes de visitar cualquier vértice a distancia k+1.

Características

  • Utiliza una cola (queue) como estructura de datos auxiliar
  • Garantiza encontrar el camino más corto en grafos sin pesos
  • Eficaz para explorar en "amplitud" (nivel por nivel)
  • Complejidad: O(V + E)

Algoritmo Paso a Paso

  1. Marcar el vértice inicial como visitado
  2. Encolarlo en la cola
  3. Mientras la cola no esté vacía:
    1. Desencolar un vértice actual
    2. Para cada vecino del vértice actual:
      1. Si el vecino no ha sido visitado:
      2. Marcarlo como visitado
      3. Encolarlo

Pseudocódigo

BFS(grafo, inicio):
    visitados = conjunto vacío
    cola = Cola()
    
    visitados.agregar(inicio)
    cola.encolar(inicio)
    
    mientras cola no esté vacía:
        vertice = cola.desencolar()
        procesar(vertice)
        
        para cada vecino en grafo[vertice]:
            si vecino no en visitados:
                visitados.agregar(vecino)
                cola.encolar(vecino)

Implementación en Python

from collections import deque

def bfs(grafo, inicio):
    visitados = set()
    cola = deque([inicio])
    visitados.add(inicio)
    resultado = []
    
    while cola:
        vertice = cola.popleft()
        resultado.append(vertice)
        
        for vecino in grafo[vertice]:
            if vecino not in visitados:
                visitados.add(vecino)
                cola.append(vecino)
    
    return resultado

# Uso
grafo = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D', 'E'],
    'D': ['B', 'C'],
    'E': ['C']
}

print(bfs(grafo, 'A'))  # ['A', 'B', 'C', 'D', 'E']

Visualización: Orden de Visita en BFS

Grafo ejemplo:

 /   / \
D   E   F

Iniciando en A:
Nivel 0: A
Nivel 1: B, C
Nivel 2: D, E, F

Orden BFS: A → B → C → D → E → F

Ventajas de BFS

  • Camino más corto: Encuentra el camino más corto en grafos sin pesos
  • Completo: Encuentra solución si existe
  • Óptimo: Garantiza la solución óptima para grafos uniformes

Desventajas de BFS

  • Memoria: Requiere guardar todos los vértices de un nivel en memoria
  • Grafos infinitos: Puede no terminar en grafos infinitos

Búsqueda en Profundidad (DFS)

¿Qué es DFS?

DFS es un algoritmo que explora el grafo avanzando lo más lejos posible por cada rama antes de retroceder. Utiliza una pila (stack) para explorar en "profundidad".

Características

  • Utiliza una pila (stack) o recursión
  • Explora profundamente antes de explorar en amplitud
  • Requiere menos memoria que BFS en algunos casos
  • Complejidad: O(V + E)

Algoritmo Paso a Paso

  1. Marcar el vértice actual como visitado
  2. Para cada vecino del vértice actual:
    1. Si el vecino no ha sido visitado:
    2. Realizar DFS recursivo en el vecino

Pseudocódigo (Versión Recursiva)

DFS(grafo, vertice, visitados):
    visitados.agregar(vertice)
    procesar(vertice)
    
    para cada vecino en grafo[vertice]:
        si vecino no en visitados:
            DFS(grafo, vecino, visitados)

Implementación en Python: Versión Recursiva

def dfs_recursivo(grafo, vertice, visitados=None):
    if visitados is None:
        visitados = set()
    
    visitados.add(vertice)
    resultado = [vertice]
    
    for vecino in grafo[vertice]:
        if vecino not in visitados:
            resultado.extend(dfs_recursivo(grafo, vecino, visitados))
    
    return resultado

# Uso
grafo = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D', 'E'],
    'D': ['B', 'C'],
    'E': ['C']
}

print(dfs_recursivo(grafo, 'A'))  # ['A', 'B', 'D', 'C', 'E']

Implementación en Python: Versión Iterativa

def dfs_iterativo(grafo, inicio):
    visitados = set()
    pila = [inicio]
    resultado = []
    
    while pila:
        vertice = pila.pop()
        
        if vertice not in visitados:
            visitados.add(vertice)
            resultado.append(vertice)
            
            # Agregar vecinos a la pila (en orden inverso)
            for vecino in reversed(grafo[vertice]):
                if vecino not in visitados:
                    pila.append(vecino)
    
    return resultado

Ventajas de DFS

  • Memoria eficiente: Requiere menos memoria que BFS en algunos casos
  • Detección de ciclos: Eficaz para detectar ciclos
  • Orden topológico: Útil para ordenamientos topológicos

Desventajas de DFS

  • No encuentra camino más corto: En general, no encuentra el camino más corto
  • Puede ser infinito: En grafos infinitos puede entrar en ciclos infinitos

Comparación: BFS vs DFS

Aspecto BFS DFS
Estructura de Datos Cola (Queue) Pila (Stack)
Complejidad Temporal O(V + E) O(V + E)
Complejidad Espacial O(V) O(h) - h = altura
Orden de Exploración Por niveles (amplitud) Por rama (profundidad)
Camino Más Corto ✓ Sí ✗ No
Detección de Ciclos ✓ Sí ✓ Sí
Orden Topológico ✗ No ✓ Sí
Implementación Iterativa Recursiva o Iterativa

¿Cuándo usar cada uno?

📌 Usa BFS si:

  • Necesitas encontrar el camino más corto
  • Trabajas con grafos por niveles
  • Quieres exploración por amplitud
  • Buscas una solución en el menor número de pasos

📌 Usa DFS si:

  • Necesitas detectar ciclos
  • Quieres hacer un ordenamiento topológico
  • La memoria es limitada
  • Exploras todas las soluciones posibles

Aplicaciones Prácticas

Aplicaciones de BFS

📡 Redes y Comunicación

Encontrar la ruta más corta en redes de computadoras.

🗺️ GPS y Navegación

Calcular la ruta más corta en sistemas de GPS.

🎮 Videojuegos

Aplicaciones de DFS

🔄 Detección de Ciclos

Detectar ciclos en grafos dirigidos y no dirigidos.

📋 Ordenamiento Topológico

Ordenar tareas con dependencias (Ej: compiladores).

🔓 Escape Rooms y Puzzles

Exploración exhaustiva de todas las soluciones.

🌳 Análisis de Árbol de Sintaxis

Compiladores utilizan DFS para analizar código.

Ejemplo Práctico: Detectar Ciclo en Grafo Dirigido

Usando DFS:

def tiene_ciclo(grafo):
    """Detecta ciclo en grafo dirigido usando DFS"""
    visitados = set()
    en_recurcion = set()
    
    def dfs(vertice):
        visitados.add(vertice)
        en_recurcion.add(vertice)
        
        for vecino in grafo.get(vertice, []):
            if vecino not in visitados:
                if dfs(vecino):
                    return True
            elif vecino in en_recurcion:
                return True  # Ciclo encontrado
        
        en_recurcion.remove(vertice)
        return False
    
    for vertice in grafo:
        if vertice not in visitados:
            if dfs(vertice):
                return True
    
    return False

# Uso
grafo_con_ciclo = {
    'A': ['B'],
    'B': ['C'],
    'C': ['A']  # Ciclo: A → B → C → A
}

print(tiene_ciclo(grafo_con_ciclo))  # True

Ejemplo Práctico: Ordenamiento Topológico con DFS

Útil para tareas con dependencias:

def ordenamiento_topologico(grafo):
    """Retorna el ordenamiento topológico del grafo"""
    visitados = set()
    pila = []
    
    def dfs(vertice):
        visitados.add(vertice)
        
        for vecino in grafo.get(vertice, []):
            if vecino not in visitados:
                dfs(vecino)
        
        pila.append(vertice)
    
    for vertice in grafo:
        if vertice not in visitados:
            dfs(vertice)
    
    return list(reversed(pila))

# Ejemplo: Tareas
# Tarea D depende de A y B
# Tarea C depende de D
tareas = {
    'A': [],
    'B': [],
    'C': ['D'],
    'D': ['A', 'B']
}

print(ordenamiento_topologico(tareas))  # ['A', 'B', 'D', 'C']

Conclusión

BFS y DFS son dos algoritmos fundamentales para recorrer grafos, cada uno con sus propias ventajas y casos de uso. BFS destaca en encontrar caminos cortos, mientras que DFS es excelente para detección de ciclos y ordenamientos topológicos.

Dominar estos algoritmos es esencial para resolver problemas complejos en ciencias de la computación y desarrollar aplicaciones eficientes.
