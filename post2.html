Introducción

Uno de los aspectos más importantes en la programación de grafos es cómo almacenarlos en memoria. Existen dos formas principales de representar un grafo:

  1. Lista de Adyacencia - Eficiente en espacio para grafos dispersos
  2. Matriz de Adyacencia - Eficiente en tiempo para consultar conexiones

Cada representación tiene ventajas y desventajas, y la elección depende del tipo de operaciones que realicemos y del espacio disponible.

Lista de Adyacencia

¿Qué es?

Una lista de adyacencia es una estructura donde se mantiene una lista (o vector dinámico) para cada vértice del grafo. Cada lista contiene todos los vértices adyacentes a ese vértice.

Ventajas

  • Eficiente en espacio: Solo ocupa O(V + E) de memoria
  • Ideal para grafos dispersos: Si hay pocos aristas respecto a vértices
  • Iteración rápida: Navegar por los vecinos es muy rápido

Desventajas

  • Consulta lenta: Verificar si existe una arista requiere buscar en la lista O(V)
  • Acceso no directo: No acceso directo en O(1) a una arista específica

Ejemplo: Grafo No Dirigido

Representación en Python:

grafo = {
    'A': ['B', 'C'],
    'B': ['A', 'C', 'D'],
    'C': ['A', 'B', 'D'],
    'D': ['B', 'C', 'E'],
    'E': ['D']
}

Ejemplo: Grafo Dirigido

Representación en Python:

grafo_dirigido = {
    'A': ['B', 'C'],
    'B': ['C', 'D'],
    'C': ['D'],
    'D': ['E'],
    'E': []
}

Ejemplo: Grafo Ponderado

Representación en Python (con pesos):

grafo_ponderado = {
    'A': [('B', 4), ('C', 2)],
    'B': [('A', 4), ('C', 1), ('D', 5)],
    'C': [('A', 2), ('B', 1), ('D', 8)],
    'D': [('B', 5), ('C', 8), ('E', 2)],
    'E': [('D', 2)]
}

Matriz de Adyacencia

¿Qué es?

Una matriz de adyacencia es una matriz cuadrada de dimensión V×V (donde V es el número de vértices). Cada celda M[i][j] contiene:

  • 1 (o true) si existe una arista entre los vértices i y j
  • 0 (o false) si no existe arista
  • Un valor (peso) si es un grafo ponderado

Ventajas

  • Consulta rápida: Verificar si existe una arista toma O(1)
  • Acceso directo: Acceso inmediato a cualquier arista
  • Operaciones matriciales: Se pueden usar algoritmos de álgebra lineal

Desventajas

  • Uso de espacio: Requiere O(V²) memoria, ineficiente para grafos dispersos
  • Iteración lenta: Navegar todos los vecinos requiere revisar toda la fila O(V)

Ejemplo: Grafo No Dirigido

A B C D E
A 0 1 1 0 0
B 1 0 1 1 0
C 1 1 0 1 0
D 0 1 1 0 1
E 0 0 0 1 0

Ejemplo: Grafo Dirigido

A B C D E
A 0 1 1 0 0
B 0 0 1 1 0
C 0 0 0 1 0
D 0 0 0 0 1
E 0 0 0 0 0

Representación en Python

Matriz de Adyacencia:

matriz = [
    [0, 1, 1, 0, 0],  # A
    [1, 0, 1, 1, 0],  # B
    [1, 1, 0, 1, 0],  # C
    [0, 1, 1, 0, 1],  # D
    [0, 0, 0, 1, 0]   # E
]

Grafo Ponderado

Con pesos en las aristas:

matriz_ponderada = [
    [0, 4, 2, 0, 0],
    [4, 0, 1, 5, 0],
    [2, 1, 0, 8, 0],
    [0, 5, 8, 0, 2],
    [0, 0, 0, 2, 0]
]

Comparación de Representaciones

Complejidad de Operaciones

Operación Lista de Adyacencia Matriz de Adyacencia
Insertar vértice O(1) O(V²)
Eliminar vértice O(V + E) O(V²)
Insertar arista O(1) O(1)
Eliminar arista O(E/V) O(1)
Verificar arista O(V) O(1)
Encontrar vecinos O(grado) O(V)
Espacio O(V + E) O(V²)

¿Cuándo usar cada una?

📌 Usa Lista de Adyacencia si:

  • El grafo es disperso (pocas aristas)
  • Necesitas iterar sobre los vecinos frecuentemente
  • El espacio en memoria es limitado
  • Realizas operaciones de inserción/eliminación de vértices

📌 Usa Matriz de Adyacencia si:

  • El grafo es denso (muchas aristas)
  • Necesitas verificar rápidamente si existe una arista
  • Usarás algoritmos que requieren acceso O(1)
  • Necesitas operaciones matriciales

Ejemplos Prácticos de Código

Implementación en Python: Lista de Adyacencia

class Grafo:
    def __init__(self):
        self.vertices = {}
    
    def agregar_vertice(self, v):
        if v not in self.vertices:
            self.vertices[v] = []
    
    def agregar_arista(self, u, v):
        if u in self.vertices and v in self.vertices:
            self.vertices[u].append(v)
            self.vertices[v].append(u)  # Para grafo no dirigido
    
    def vecinos(self, v):
        return self.vertices.get(v, [])
    
    def existe_arista(self, u, v):
        return v in self.vertices.get(u, [])

# Uso
g = Grafo()
for nodo in ['A', 'B', 'C', 'D', 'E']:
    g.agregar_vertice(nodo)
g.agregar_arista('A', 'B')
g.agregar_arista('A', 'C')

Implementación en Python: Matriz de Adyacencia

class GrafoMatriz:
    def __init__(self, n):
        self.n = n
        self.matriz = [[0] * n for _ in range(n)]
        self.vertices = {}
        self.indice = 0
    
    def agregar_vertice(self, v):
        if v not in self.vertices:
            self.vertices[v] = self.indice
            self.indice += 1
    
    def agregar_arista(self, u, v):
        i = self.vertices[u]
        j = self.vertices[v]
        self.matriz[i][j] = 1
        self.matriz[j][i] = 1  # Para grafo no dirigido
    
    def existe_arista(self, u, v):
        i = self.vertices[u]
        j = self.vertices[v]
        return self.matriz[i][j] == 1

# Uso
g = GrafoMatriz(5)
for nodo in ['A', 'B', 'C', 'D', 'E']:
    g.agregar_vertice(nodo)
g.agregar_arista('A', 'B')

Conclusión

La representación de un grafo es una decisión crucial que afecta el desempeño de nuestro programa. Las listas de adyacencia son ideales para grafos dispersos, mientras que las matrices de adyacencia brillan en grafos densos y cuando necesitamos acceso rápido a aristas específicas.
