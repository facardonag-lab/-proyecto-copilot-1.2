## 📤 Cómo Publicar en GitHub Pages

### Paso 1: Crear repositorio en GitHub
1. Ir a https://github.com/new
2. Nombre del repo: `proyecto-copilot`
3. Hacer público (public)
4. Click en "Create repository"

### Paso 2: Agregar remoto y hacer push
```bash
cd d:\TRABAJO\ ESTRUCTURA\ DE\ DATOS\proyecto-copilot

# Agregar remoto (reemplaza USER con tu usuario)
git remote add origin https://github.com/USER/proyecto-copilot.git

# Cambiar rama a main si es necesario
git branch -M main

# Hacer push
git push -u origin main
```

### Paso 3: Habilitar GitHub Pages
1. Ir a Settings de tu repositorio
2. Ir a Pages (en la sección Code and automation)
3. Source: Deploy from a branch
4. Branch: main, carpeta: / (root)
5. Click Save

### Paso 4: Acceder al blog
Tu blog estará en:
```
https://[tu-usuario].github.io/proyecto-copilot/
```
