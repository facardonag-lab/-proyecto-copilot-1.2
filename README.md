# 📊 Blog Técnico: Estructura de Datos - Grafos

## Descripción del Proyecto

Este es un blog técnico completo dedicado a la estructura de datos **Grafos** (Graphs). El proyecto combina desarrollo web moderno (HTML5, CSS3, JavaScript) con contenido técnico de alta calidad sobre algoritmos y estructuras de datos.

## 🎯 Objetivos

- ✅ Crear contenido técnico de calidad sobre grafos
- ✅ Implementar un sitio web responsivo y atractivo
- ✅ Publicar en GitHub Pages
- ✅ Aplicar buenas prácticas de desarrollo web

## 📚 Artículos Incluidos

### Post #1: Introducción a los Grafos: Nodos, Aristas y Tipos
- **Contenido:** Definición de grafos, conceptos clave (vértices, aristas), tipos de grafos (dirigidos, no dirigidos, ponderados)
- **Visualización:** Diagrama interactivo de un grafo con 5 nodos
- **Ejemplo:** Código en Python mostrando cómo representar un grafo

### Post #2: Representación de Grafos
- **Contenido:** Dos formas principales de representar grafos en memoria
  - Lista de Adyacencia (eficiente en espacio para grafos dispersos)
  - Matriz de Adyacencia (eficiente en tiempo para consultas)
- **Visualización:** Tablas comparativas y matrices de ejemplo
- **Implementación:** Código Python para ambas representaciones

### Post #3: Algoritmos Fundamentales de Recorrido
- **Contenido:** Dos algoritmos esenciales
  - BFS (Breadth-First Search) - Búsqueda en Amplitud
  - DFS (Depth-First Search) - Búsqueda en Profundidad
- **Visualización:** Diagramas de orden de visita
- **Implementación:** Código Python recursivo e iterativo
- **Aplicaciones:** Casos de uso en el mundo real

## 🔧 Instalación y Uso

### Requisitos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Git (para clonar el repositorio)

### Pasos
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/[tu-usuario]/proyecto-copilot.git
   ```

2. Abrir `index.html` en el navegador:
   ```bash
   cd proyecto-copilot
   # Opción 1: Abrir directamente
   start index.html  # Windows
   open index.html   # macOS
   xdg-open index.html  # Linux
   
   # Opción 2: Usar un servidor local
   python -m http.server 8000
   # Luego visitar: http://localhost:8000
   ```

## 🌐 Publicación en GitHub Pages

### Configuración
1. Hacer push del código a GitHub:
   ```bash
   git add .
   git commit -m "Agregar blog técnico de grafos"
   git push origin main
   ```

2. Ir a Settings → Pages
3. Seleccionar "Deploy from a branch"
4. Seleccionar rama "main" y carpeta "root"
5. Guardar cambios

### URL de publicación
Tu blog estará disponible en:
```
https://[tu-usuario].github.io/proyecto-copilot/
```
